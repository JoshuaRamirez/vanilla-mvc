# Code of conduct

vanilla-mvc adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, in full. In short: be welcoming, be kind, disagree about code and not about
people, and assume good intent.

It applies in the repository, its issues and pull requests, and anywhere someone represents the
project.

## Reporting

Report unacceptable behaviour to the maintainer privately, through the contact on
[the maintainer's GitHub profile](https://github.com/JoshuaRamirez). Reports are read, kept
confidential, and answered. The Covenant's enforcement guidelines say what may follow.
